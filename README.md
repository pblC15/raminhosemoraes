# Raminhos & Moraes

Landing page da Raminhos & Moraes — limpezas técnicas e pós-obra, residencial, comercial e industrial.

## Antes de publicar
- **Instagram:** abra `script.js` e escreva o nome de utilizador em `INSTAGRAM` (sem @). Enquanto estiver vazio, os botões de Instagram ficam escondidos.
- **WhatsApp:** já configurado com 938 213 616 (linha 1) e 935 789 111 (linha 2), no topo de `script.js`.
- **Serviços e fotos:** em `index.html`, procure ✏️.

## Publicar no GitHub Pages
1. Crie um repositório novo no GitHub (ex.: `raminhos-moraes`).
2. Envie todos os ficheiros desta pasta, incluindo `assets/` e `.nojekyll`.
3. Em **Settings → Pages**, escolha *Deploy from a branch*, branch `main`, pasta `/ (root)` e clique **Save**.
4. Em 1–2 minutos o site fica em `https://SEU-UTILIZADOR.github.io/raminhos-moraes/`.

## Estrutura
```
index.html          página
style.css           estilos
script.js           WhatsApp, Instagram, orçamento rápido e a foto para "limpar"
assets/             logótipo em branco (fundo transparente), folhas, favicon, imagem de partilha
assets/trabalhos/   fotos dos trabalhos
.nojekyll           evita processamento Jekyll
```
